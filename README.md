Python scripts for extracting and converting resources from Midnight Club: Los Angeles.



xcs\_textures\_extraction - Batch extracting textures from xcs files



xcs2obj - Converting xcs to obj with texture extraction



xrsc2obj - Converting xrsc to obj with texture extraction



Usage:



python xcs\_textures\_extraction.py <xcs\_folder> <strings.txt> <png\_folder>



python xcs2obj.py name.xcs -o name.obj --flags



python xrsc2obj.py name.xrsc name.obj --flags



\-h for help
